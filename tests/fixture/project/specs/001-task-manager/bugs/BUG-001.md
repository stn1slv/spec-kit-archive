# BUG-001: Pagination skips tasks when two tasks share a deadline

**Status**: Fixed
**Reported**: 2026-07-10
**Related**: FR-003

## Report

When two tasks have exactly the same deadline, the paginated list (`GET /tasks`) can skip one of them at a page boundary, because ordering by deadline alone is not stable.

## Fix

Ordering changed to `(deadline, id)` so pagination is stable. FR-003 should be read as requiring a stable, deterministic order.

## Amendment

FR-003 is amended: the task list order is deadline first, then task id as a tiebreaker.
