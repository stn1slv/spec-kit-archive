# BUG-002: Virus scan misses nested archives

**Type**: Implementation drift
**Severity**: High
**Status**: Fixed
**Reported**: 2026-08-09

## Report

A file inside a zip inside a zip is never scanned; the scan gate marks the outer archive clean and the nested payload is downloadable.

## Root Cause Analysis

**Issue:** The scanner processed only the top level of an uploaded archive.
**Root Cause:** The scan gate passed the raw upload to the scanner without expanding archives, and the scanner's default recursion is off.
**Prevention Rule:** The scan gate must expand archives one level and scan each member; any deeper nesting is rejected rather than trusted.
